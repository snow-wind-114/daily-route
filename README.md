# 每日安排

Daily Route 是一个面向安卓手机的本地日程工具。网页版用于预览、匿名编辑、导出活动和下载 APK；安卓版提供本地账户、普通通知、精确闹钟、桌面组件和更新检查。

- 正式网页：<https://snow-wind-114.github.io/daily-route/>
- 安卓 APK：<https://github.com/snow-wind-114/daily-route/releases/latest/download/daily-route.apk>
- GitHub 仓库：<https://github.com/snow-wind-114/daily-route>

## v0.6.1 功能与修复

- 今天：00:00–24:00 时间轴，时间精确到分钟，刻度每 30 分钟。
- 主视图覆盖当前自然年 1 月 1 日至 12 月 31 日，可查看今年已过去日期。
- 活动分为定期、待办和打卡；三类活动分别展示，并共用同一套全局分类。
- 分类已升级为全局分类；同一个分类可以同时包含定期、待办和打卡。
- 新建定期、待办和打卡表单自动保存为三份独立草稿；再次点“+”可从最近草稿继续。
- 活动页支持按当前搜索结果多选，并批量归类、暂停、归档或永久删除。
- 定期支持 1–14 天重复间隔、1–20 次或重复至年底，不能跨午夜或重叠。
- 待办支持截止日期、分钟级截止时间、备注和提前 0–30 天通知/闹钟提醒。
- 打卡支持今天页快捷打卡、专属月历和每日通知/闹钟提醒；同一天最多一次。
- 多个打卡项目在相同时间、相同提醒方式下会合并为一条提醒，当天已打卡则跳过。
- 回顾页只展示今年，可浏览今天及过去日期；只有今天可编辑。
- 今天页可一键打开当前选中日期的对应回顾。
- 每日回顾包含今日总结、感想、灵感和首次保存时冻结的当天活动摘要。
- 每日回顾提醒默认关闭，可在回顾页设置普通通知时间。
- 回顾页可按选中日期导出本周、本月或本年度 Markdown 回顾册。
- 本周页将七天定期安排与本周待办、打卡分开显示，打卡项目每周只出现一次。
- 本周页和活动页的打卡月历仅供查看；历史打卡不能再补打或取消。
- 编辑重复活动时可选择“只修改这一次”“修改本次及以后”或“暂停整个活动”。
- 单次调整仍属于原活动系列；暂停期间不计占用、不提醒，也不消耗有限次数。
- 本月主日历以 2 小时刻度显示定期占用，并在日期右上角显示待办截止数量。
- 定期活动使用暂停、归档、永久删除整个系列三种操作；单次变化只通过“只修改这一次”处理。
- 完成项目进入归档，可在归档页切换年份并恢复或删除；恢复定期项目时先编辑合法日期再重新启用。
- 安卓从 12 月 1 日至 31 日提示迁移，并在 12 月 1 日发送一次普通通知。
- 年度迁移只包含定期和打卡，包含已暂停项目；确认后立即创建下一年活动。
- 年度迁移按统一分类分组，可选择整个分类或单独调整项目。
- 1 月首次打开可补做迁移，并在导出或明确放弃后清除旧回顾。
- 安卓提醒分为普通通知和精确闹钟。闹钟使用应用自有原生排程器，每个系列始终只保留最近一次系统唤醒，触发后再安排下一次。
- 安卓账户面板提供通知诊断、测试通知、测试闹钟、本地恢复点、JSON 导入导出和更新检查。
- 安卓桌面组件按“左侧定期、右上今日截止、右下打卡汇总”分区显示。
- 顶栏提供完全离线的分主题使用教程。
- 活动工具栏和批量选择按钮使用等高、等宽布局，移动端不再出现一个按钮独占一行。
- 专注页使用独立滚动区域和统一页面内边距，可正常浏览、滚动到壁纸区。
- 教程在移动端使用两列标签和受约束的可滚动正文，不再被状态栏或弹窗边缘遮挡。
- 新增专注页：可创建专注/休息单次项目和顺序周期专注，记录累计执行时间。
- 专注运行页随机显示本地壁纸和语句，保持亮屏并进入沉浸模式；离开应用自动暂停。
- 可选专注密码用于提前结束；安卓可用本地账户密码重置，网页需明确输入确认文字。
- 自定义壁纸压缩后只保存在当前设备，不进入 JSON 备份；专注密码哈希也不会进入 JSON。
- 壁纸库显示真实图片缩略图和按运行页比例裁切的预览。

当前版本为 `v0.6.1`。安卓存储继续使用 v6 键并兼容 v2–v5；JSON 备份为 v6。网页继续使用原 `daily-route.storage.v1` 键。

v5→v6 升级会按本轮产品规则清空旧分类定义，并把所有旧活动转为未分类；v1–v5 旧备份中的分类也不会恢复。分类名称若有价值，请在升级前自行记录。

## 提醒和组件排查

- 账户面板会显示当前版本、通知权限、精确闹钟权限和两个通知通道的状态。
- 如果“活动闹钟”通道被系统关闭，闹钟会自动改用“活动通知”通道。
- “测试闹钟”会立即安排测试，不会先跳转系统设置；权限或通道缺失时会明确降级。
- 如果组件列表没有刷新，请确认应用为 v0.6.1，然后重启手机或重启当前桌面启动器。
- 组件名为“今日活动”，所属应用为“每日安排”。

## 网页版与安卓版

网页版不需要登录，也没有真实系统提醒或桌面组件。网页活动只保存在当前浏览器、当前网址对应的 `localStorage` 中。

安卓版使用独立的应用内存储。网页与安卓不会自动同步；首次迁移时在网页导出 JSON，再在安卓版登录后导入。

安卓应用更新保留账户和活动的前提是：

- 新 APK 使用相同包名 `com.snowwind114.dailyroute`。
- 新 APK 使用同一 release keystore 签名。
- 新 APK 的 `versionCode` 高于已安装版本。

```powershell

```

## 安装和更新安卓版

1. 用安卓浏览器打开正式网页并下载 APK。
2. 首次安装时允许当前浏览器“安装未知来源应用”。
3. 安卓 13 及以上会在首次启用提醒时请求通知权限。
4. 首次选择“闹钟”时还会打开“闹钟和提醒”特殊权限设置。
5. 后续在应用账户面板点“检查更新”，再通过系统浏览器下载并覆盖安装。

应用本身不申请“安装未知应用”权限，也不会静默安装。

## 提醒与权限

普通通知允许系统延迟。精确闹钟由 `DailyRouteAlarmSchedulerPlugin` 使用 `setExactAndAllowWhileIdle` 排程，但仍可能受到厂商后台策略、勿扰模式和系统限制影响。打卡提醒每天最多一次，默认 `21:00`；已经打卡、暂停或归档时不会提醒。

APK 权限范围：

- `POST_NOTIFICATIONS`：显示本地通知。
- `RECEIVE_BOOT_COMPLETED`：重启后恢复尚未发生的提醒。
- `SCHEDULE_EXACT_ALARM`：用户选择闹钟提醒时使用的特殊权限。
- `INTERNET`：仅在用户主动检查更新时访问 GitHub Pages 版本清单。
- `WAKE_LOCK` 和 `VIBRATE`：本地提醒与振动所需的普通权限。

不申请位置、相机、通讯录、麦克风、广泛文件存储、电池优化白名单或应用安装权限。

## 构建

需要 Node.js、Android Studio、Android SDK Platform 36、Build Tools 36.1 和 JDK 21。

```powershell
npm install
npm test
npm run check
npm run cap:sync
```

构建 APK：

```powershell
$env:JAVA_HOME = 'E:\Android\Android Studio\jbr'
cd .\android
.\gradlew.bat assembleDebug --no-daemon
.\gradlew.bat assembleRelease --no-daemon
```

输出：

```text
android/app/build/outputs/apk/debug/app-debug.apk
android/app/build/outputs/apk/release/app-release.apk
```

## 签名与发布

长期签名材料：

```text
android/daily-route-release.jks
android/keystore.properties
```

两者都被 Git 忽略。请单独备份；丢失后无法覆盖升级，通常只能卸载重装并丢失应用本地数据。

Release APK 必须命名为 `daily-route.apk` 并上传到最新 GitHub Release。网页固定下载地址依赖该资产名。

版本发布前必须同步：

- `package.json`
- `android/app/build.gradle`
- `app.js` 中的 `APP_VERSION` 和 `APP_VERSION_CODE`
- `update.json`

`npm run check` 会阻止这些版本号不一致。

## 数据与恢复

- 安卓账户密码使用 PBKDF2 哈希，活动内容本身不加密。
- JSON v6 备份包含活动、统一分类、回顾、专注项目、流程、累计值、语句、壁纸元数据和年度迁移完成年份，不包含账户凭据、专注密码哈希、壁纸图片或登录状态。
- 回顾正文与活动一样为本地明文；账户密码不会加密回顾内容。
- 安卓自动保留最近 5 个应用内恢复点，但清除数据、卸载、换机或设备损坏后不会保留。
- JSON 手动导出是唯一能离开应用私有空间的活动备份方式。
- 换机流程：新手机注册本地账户，再导入此前导出的 JSON；账户密码不迁移。
