# 每日安排

一个面向安卓手机的本地离线日程 PWA。活动数据只保存在当前浏览器的本地存储中，不需要账号或服务器。

主要页面包括今天时间轴、本周安排、本月占用概览和活动项目列表。月历使用 12 格占用刻度，每格代表 2 小时。活动页会按最近一次发生日期排序进行中项目，并允许搜索及删除已结束项目。

## 本地运行

```powershell
node .\serve.mjs
```

在电脑浏览器打开 `http://localhost:4173`。

电脑上的这次调试只会产生电脑浏览器自己的本地数据，不会同步到手机。

## 手机安装

PWA 在首次安装时需要 HTTPS 地址。正式使用时，应将本项目部署到一个固定 HTTPS 域名，然后在安卓 Chrome 中打开并选择“安装应用”或“添加到主屏幕”。通过局域网 IP 的普通 HTTP 地址可以在手机上临时查看页面，但浏览器不会提供完整的离线缓存和安装能力。

GitHub Pages 的具体发布步骤见 [GITHUB_PAGES.md](./GITHUB_PAGES.md)。仓库包含自动部署到 GitHub Pages 的 Actions 工作流。

## 验证

```powershell
node --test
```

## 数据说明

- 数据保存在浏览器的本地存储中。
- 清除浏览器站点数据、清除应用数据或卸载相关浏览器应用会导致数据丢失。
- 使用无痕模式时，关闭窗口后数据会消失。
- 更换浏览器、切换浏览器用户配置或改用另一个域名时，原数据不会自动出现。
- 系统清理存储、重置设备或设备损坏也可能导致数据丢失。
- 应用不会上传活动数据，也不会自动备份。
